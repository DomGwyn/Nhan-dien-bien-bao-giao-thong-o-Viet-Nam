# Vietnamese Traffic Sign Detection

## Giới thiệu
Nhận diện biển báo giao thông Việt Nam bằng YOLOv8 và EasyOCR.

## Công nghệ sử dụng
- Python
- YOLOv8
- OpenCV
- EasyOCR

## Huấn luyện
python train_yolo.py

## Demo
python test_yolo.py

## Kết quả
- Nhận diện 56 loại biển báo
- OCR đọc biển báo tốc độ
